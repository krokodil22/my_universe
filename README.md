# Моя вселенная

Статический редактор города на HTML, CSS и JavaScript. Сборка, серверная база данных и ключи API не нужны.

## Запуск

Из каталога репозитория:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Откройте приложение в браузере. Для публикации разместите `index.html`, `style.css` и `app.js` на любом статическом хостинге (например, GitHub Pages).

## Возможности

- Загрузка карты и изображений PNG/JPG/JPEG до 10 МБ на файл.
- Библиотека домов, транспорта и жителей; демонстрационные иллюстрации включены.
- Перетаскивание из библиотеки на карту; на сенсорном устройстве нажмите карточку для добавления в центр.
- Перемещение неподвижных объектов; редактирование названия, описания, размера, основного изображения, галереи и слоя через левую панель. Изменения сохраняются сразу и видны на карте.
- Для транспорта и жителей укажите точки маршрута и нажмите «Готово». Маршрут замыкается, движение повторяется бесконечно. Маршрут можно изменить через левую панель объекта. 
- Редактируемые название города и законы.
- Автоматическое локальное сохранение в IndexedDB, экспорт и импорт JSON вместе с изображениями.

Данные привязаны к браузеру и адресу сайта. Для резервной копии и переноса используйте экспорт. Совместного редактирования и синхронизации между устройствами нет. Очистка данных браузера удаляет локальную вселенную. Используются системные шрифты, внешние запросы не требуются.

## Запуск на GitHub Pages

1. В репозитории откройте **Settings → Pages**.
2. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
3. Откройте **Actions → Publish GitHub Pages → Run workflow → main → Run workflow**.
4. После успешного выполнения сайт будет доступен по адресу https://krokodil22.github.io/my_universe/ .

При следующих изменениях в `main` сайт обновится автоматически. Для работы приложения не нужны сервер или установка зависимостей. Workflow публикует только HTML, CSS и JavaScript приложения.

## Камера, маршруты и слои

- Размер мира — 3000 × 2100. Перетаскивайте фон мышью или пальцем, чтобы перемещать камеру. Колесо мыши и кнопки −/＋ меняют масштаб; ⊡ показывает всю карту. Добавление нажатием на библиотеку размещает объект в центре текущего вида.
- Нажатие на объект открывает редактор слева. Поля применяются сразу; «Готово» и × закрывают панель. Основное изображение можно заменить, изображения галереи — добавлять и удалять.
- У каждого объекта есть слой от 0 до 999: большее значение располагает его впереди. При одинаковом слое впереди объект, добавленный позже.
- Транспорт и жители движутся по замкнутым маршрутам. Для движения влево изображение зеркально отражается; исходное изображение считается направленным вправо.
- При создании или изменении маршрута слева показаны все отрезки, включая замыкание к первой точке. Для каждого задаётся отдельный слой, который используется вместо общего слоя объекта во время движения по этому отрезку.
- Во время задания маршрута фон по-прежнему можно перетаскивать. Короткое нажатие добавляет точку; «Убрать точку» отменяет последнюю. «Отмена» сохраняет прежний маршрут при редактировании и удаляет новый объект при первичном размещении.
- Сохранённые ранее города и файлы экспорта поддерживаются: отсутствующий слой считается нулевым, отсутствующие слои отрезков используют слой объекта.

## Время и ночное освещение

- При отдалении карта центрируется по каждой оси, по которой помещается целиком. Кнопка ⊡ показывает всю карту по центру.
- Над картой находятся часы: время идёт автоматически со скоростью 10 минут мира за реальную секунду. Полный цикл занимает 2 минуты 24 секунды. Поле времени позволяет установить его вручную; переключатель «Ход времени» останавливает или возобновляет часы.
- День длится с 08:00 до 18:00, сумерки — до 20:00, ночь — до 06:00, рассвет — до 08:00. Карта и объекты плавно темнеют в переходные часы. При закрытой вкладке время тоже продолжает идти, если часы не были остановлены.
- В редакторе дома или транспорта нажмите на основное изображение, чтобы добавить огонёк. Выберите его на изображении или по номеру; настройте цвет, яркость, ширину и высоту. «Ночной предпросмотр» позволяет проверить освещение независимо от часов мира. В дневном редакторе огни слегка видны как метки для настройки; на самой карте днём они невидимы.
- При загрузке одного изображения дома или транспорта сразу открывается редактор освещения. Огни библиотечного изображения копируются при последующем размещении; ранее размещённые экземпляры редактируются отдельно.
- Огни прикреплены к изображению: масштабируются, движутся и зеркально отражаются вместе с объектом, учитывая его слой. Это декоративное свечение окон и фар, без расчёта теней и освещения соседних объектов.
- Часы и настройки огней сохраняются в браузере и входят в экспорт. Ранее сохранённые миры открываются с временем 12:00 и включёнными часами.

## Остановки и видимость на маршруте

Точки маршрутов транспорта и жителей подписаны цифрами на карте и в редакторе слева. В каждой точке можно задать:

- длительность остановки в **реальных секундах** (0 — без остановки);
- показывать или прятать объект от этой точки до следующей, включая остановку в этой точке;
- слой следующего отрезка, включая замыкание последней точки к первой.

Настройки повторяются на каждом круге. Скрытый объект продолжает двигаться и появится в следующей точке с режимом «Показывать объект». Открыть его редактор можно через «Объекты на карте» под библиотекой; при редактировании маршрута объект временно виден. Старые маршруты работают без остановок и скрытия.

Ночь стала темнее; переходы рассвета и сумерек остаются плавными. Даже ручная смена времени плавно меняет освещение примерно за 1,5 секунды.

## Режим просмотра

Кнопка «↗ Режим просмотра» открывает текущий сохранённый мир в отдельной вкладке (`?view=1`). Завершите или отмените настройку маршрута перед открытием просмотра.

В этой вкладке можно перемещать камеру, изменять масштаб и нажимать на объекты. Карточка слева показывает название, изображение, описание и галерею; закрывается кнопкой × или Escape. Настройки и библиотека недоступны, объекты нельзя перемещать, просмотр не записывает изменения в хранилище. Часы, ночные огни и движение продолжают работать.

Просмотр загружает сохранённое состояние при открытии или перезагрузке вкладки. Для отображения последующих изменений из редактора перезагрузите вкладку просмотра. Мир хранится в браузере: ссылка просмотра сама по себе не переносит его на другое устройство и не является публичной публикацией города.

В режиме просмотра карта занимает всё окно браузера: шапка, заголовки, библиотека и подсказки скрыты. Часы находятся поверх карты справа сверху, масштаб — справа снизу. Карточки объектов появляются слева поверх карты на полупрозрачном фоне и не меняют размер карты; на небольшом экране размещаются ниже часов.

## Несколько городов

В блоке «Мои города» выберите проект или нажмите «＋ Новый город» и задайте название. Каждый город имеет отдельные карту, библиотеку, объекты, законы, часы и настройки освещения. Новый город создаётся без размещённых объектов, с начальной библиотекой. Старый сохранённый мир автоматически переносится в первый проект.

«Удалить» удаляет текущий город только после обязательного подтверждения с его названием. Отмена ничего не меняет. Удаление необратимо; перед ним можно экспортировать город. После удаления последнего проекта создаётся пустой «Новый город», о чём предупреждает подтверждение.

Просмотр привязан к ID выбранного города: переключение проекта в редакторе не меняет открытый просмотр. Если город удалён, при перезагрузке его просмотра показывается сообщение об отсутствии проекта. Экспорт и импорт относятся к текущему городу. Все проекты хранятся локально в этом браузере.

Действия «Новый город» и «Удалить» находятся в скрытом меню по кнопке ⋯ в блоке «Мои города». Меню закрывается при выборе действия, нажатии Escape или клике вне блока. Подтверждение удаления сохранено.

В начальной библиотеке оставлена одна заготовка дома. В старых проектах удаляются только три неизменённые демонстрационные карточки; пользовательские изображения, изменённые заготовки и уже размещённые дома сохраняются.
